This repository is a research scaffold for OpenRocket + CheerpJ compatibility testing.

It is not an official OpenRocket distribution and not an official CheerpJ package.

The purpose of this project is to provide a documented, browser-based environment for testing whether the existing Swing application can run inside a browser using CheerpJ, without converting the UI to a React implementation.

The project intentionally does not claim that the upstream OpenRocket application is already working in-browser. The actual OpenRocket source, JAR outputs, and compatibility evaluation must be performed in the corresponding research phase.

OpenRocket is published under the GNU GPLv3 license. Any derivative or distribution of OpenRocket assets must comply with the upstream licensing conditions and any additional third-party terms.

CheerpJ is a third-party product with its own licensing and usage terms. Use it in accordance with the vendor's documentation and terms.

This project includes placeholder runtime files and sample assets only. Replace them with the actual OpenRocket build outputs before running a real compatibility test.

The file and code in this repository are intended for technical evaluation, not for production deployment or official distribution.
