# Performance and memory note

This project defines the measurement plan for the later validation phase.

The actual benchmark numbers are intentionally left blank because the upstream OpenRocket application is not included in this repository.

Planned checks:
- cold startup
- warm startup
- `.ork` load time
- simulation time
- graph render time
- 3D render time
- browser memory footprint

The final recommendation must be based on measured evidence, not on a successful static scaffold alone.
